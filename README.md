# 🌦️ Weather Forecast App

An elegant and responsive Weather Forecast web application built using **React.js, Vite, CSS, and OpenWeatherMap API**.  
It allows users to quickly search any city worldwide and view **real-time weather conditions**, including temperature, humidity, wind speed, and weather details through a clean modern interface.

## 🚀 Features
- 🔍 Search weather by city name  
- 🌡️ Real-time temperature updates  
- ☁️ Weather condition descriptions  
- 💧 Humidity level display  
- 🌬️ Wind speed information  
- ❌ Error handling for invalid city names  
- 📱 Responsive modern UI  
- 🎨 Attractive background and styled weather cards  

---

## 🧩 Tech Stack
- **React.js** – Frontend framework  
- **Vite** – Fast development and build tool  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6+)** – Functionality and API integration  
- **OpenWeatherMap API** – Live weather data source
